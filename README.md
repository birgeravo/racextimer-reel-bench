# RaceExTimer reel test bench

A single-page test bench for the phone questions in the RaceExTimer reels plan:
viewport height, snap per fling, nested carousels, tap/double-tap/hold, comment
layouts, a motion scene, a WebGL background, photos, endurance, haptics, theme and
view-timeline transitions.

Open it on a phone: https://birgeravo.github.io/racextimer-reel-bench/

Results are saved on each device (no shared database outside claude.ai). Use
**Results → Copy as JSON** on each phone to collect them.

The photos are AI-generated demo images of fictional people.
